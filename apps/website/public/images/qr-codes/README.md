# Transitional QR Assets

These files remain only where an approved public page or existing printed artifact still references them. They are not the production source of truth.

`Ramsey-USA/mh-document-factory` owns QR generation, branded document placement, scan verification, and release evidence. This website owns stable controlled destinations and may retain a QR image only while a verified public dependency exists.

Do not regenerate, mirror, or bulk-export QR images from this repository. New QR assets require a factory release receipt, an approved stable destination, and a scan test before publication.
