# SEO Terminology Standard

**Category:** Branding - SEO Language Standard
**Last Updated:** August 5, 2026
**Status:** Official MH Branding Standard

## Purpose

Set a clear, repeatable rule for search-facing copy: use professional construction terminology first, and use military-themed language only as subtle supporting context.

This SEO rule remains compatible with `documents/content/terminology-library.json` (Brand Terms Library v2.1),
which governs term expansions for non-SEO surfaces and is synced from `documents/input/02-strategy-and-business-dev/mh-branding-terminology-library-v1-0-draft.docx`.

## Scope

This standard applies to all search-facing metadata and schema content, including:

- Page title tags
- Meta descriptions
- Open Graph and Twitter titles/descriptions
- Structured data descriptions
- Keyword sets

## Required Precedence

1. Construction terminology first.
2. Veteran or military context second, only when it improves trust framing.

## Approved Primary Terms

- New Construction
- Tenant Improvements
- Interior Buildouts
- Preconstruction Planning
- Project Management
- Construction Management
- Field Coordination
- Quality Control

## Restricted Primary Labels

Do not use these as the primary SEO label when a construction equivalent exists:

- Mission-Ready Construction
- Mission-Ready Fit-Outs
- Mission Planning and Predeployment
- Mission Management

## Implementation Rules

- Use plain, industry-recognized construction terms in title tags and top-priority keywords.
- Keep veteran-owned references factual and secondary.
- Preserve trust and accreditation language while avoiding slogan-heavy SEO labels.
- Prefer tenant improvements over fit-outs in U.S. public-facing SEO copy unless project context requires fit-out terminology.

## Examples

```text
Preferred: Services | New Construction & Major Renovations
Avoid: Services | Mission-Ready Construction

Preferred: Tenant Improvements & Interior Buildouts
Avoid: Mission-Ready Fit-Outs

Preferred: Project Management & Coordination
Avoid: Mission Management
```
