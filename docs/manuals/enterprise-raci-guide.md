## Quick Summary

This guide captures the current markdown-facing baseline for enterprise RACI ownership across the MH document ecosystem.

Use it when updating document-family ownership, approval routing, or cross-functional accountability language so those changes stay aligned with the controlled 01 Core Doctrine source set.

## RACI Legend

- `R` = Responsible: performs the work.
- `A` = Accountable: owns the result and final approval.
- `C` = Consulted: provides required input.
- `I` = Informed: stays aware of status and outcome.

## Governance Rule

The source doctrine treats this matrix as mandatory for enterprise control and document-family accountability. Deviations require formal approval through the controlled change path.
