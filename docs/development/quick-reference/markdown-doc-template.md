# Markdown Document Template

**Category:** Development - Documentation
**Last Updated:** August 2026
**Status:** Active

## Quick Summary

Use this layout when you want a document that is easy to scan, easy to maintain, and consistent with the rest of the documentation set.

- Start with a plain-language summary.
- Explain when the page should be used.
- Break the body into short, task-based sections.
- End with clear next steps or related references.

## When to Use This Format

Use this template for guides, playbooks, reference pages, and examples that need to be easy to navigate quickly.

## What You'll Find

- A short overview at the top
- A clear purpose or use case
- A simple workflow or checklist
- Related links and supporting references

## Suggested Structure

1. **Title** — Use a clear, direct page name.
2. **Summary block** — Include category, last updated, and status.
3. **Quick Summary** — Add 3-5 bullets that explain the page in plain language.
4. **When to Use This** — Describe the situation or audience.
5. **Core Content** — Use short sections with practical guidance.
6. **Related Resources** — Link to supporting docs and next steps.
