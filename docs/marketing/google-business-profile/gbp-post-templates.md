## Purpose

This file provides approved Google Business Profile post starters for MH Construction. Use these templates to publish short-form, local-trust content that stays aligned with MH brand language, proof discipline, and service-area messaging.

These are starting points, not copy-paste mandates. Replace every placeholder with verified project facts, approved stakeholder language, and location-specific details that can be supported publicly.

## Usage Rules

- Lead with construction delivery language first.
- Keep veteran-owned framing factual and secondary to the project update.
- Publish only approved facts, visible milestones, and low-risk proof.
- Prefer clear scope, accountable delivery, dependable follow-through, and trusted handoff language.
- Use the MH primary line exactly as written when a slogan line is needed: **Built on Quality, Backed by Trust.**

## ✏️ **Customization Guidelines**

**Before Posting, Always:**

1. Replace [BRACKETED] placeholders with actual information
2. Add relevant approved photos when available
3. Verify all contact info is current
4. Check for typos and formatting
5. Confirm the post matches the correct lifecycle phase, if project-based
6. Verify the proof set is strong enough for public release
7. Include specific website links when appropriate
8. Use hashtags sparingly and only when they help local discovery

**Character Limits:**

- **Preferred approach:** Keep GBP copy short, factual, and locally relevant.
- **Working target:** Use the shortest version that still communicates the approved point clearly.
- **Photos:** Use approved visuals that match the update and do not expose sensitive details.

**Best Posting Times:**

- Monday: 7-9 AM
- Wednesday: 1-3 PM
- Friday: 10 AM - 12 PM
