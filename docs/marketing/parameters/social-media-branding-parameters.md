# Social Media Branding Parameters (Shared Campaign Baseline)

**Category:** Marketing - Strategy Baseline  
**Last Updated:** July 31, 2026 (Shared Guide Congruency Update)

## Purpose

Define the MH baseline parameters for project social media marketing and stakeholder-facing campaign language so every project starts from one consistent brand framework.

This is a baseline, not a rigid script. Every project remains unique, and cadence, proof depth, and content length can be adjusted by scope, phase, owner preferences, and field conditions.

Use this document to keep project marketing relationship-first, evidence-backed, and aligned with the approved MH construction-first brand voice.

This file is the shared parameter baseline for both the Marketing Strategy Guide and the Sales/Estimating Guide whenever messaging, proof, lifecycle language, or channel planning crosses between pursuit, public narrative, and post-award communication.

## Canonical MH Branding Parameters

### 1) Positioning Hierarchy

- Lead with construction delivery language first.
- Position veteran field standards second as credibility support.
- Keep communication relationship-first, factual, and no-hype.
- Favor wording that reinforces clear scope, accountable delivery, dependable follow-through, and trusted handoff.

### 2) Slogan and Message Stack

- Primary line: **Built on Quality, Backed by Trust.**
- Supporting lines can be rotated by context, but must not conflict with the primary line.
- For Spanish-facing surfaces, keep the English primary line with Spanish companion translation when feasible.
- Supporting lines should reinforce Ground Truth, Zero-Gap Accountability, Handshake Pride, and long-term relationship continuity.

### 3) Trust and Proof Rules

- Publish only evidence-gated updates tied to actual project milestones.
- Prefer documented proof: completed scope photos, milestone notes, approved project facts, and verified outcomes.
- Do not publish speculative completion claims, unverified performance claims, or internal-only assumptions.
- When approvals are incomplete or field conditions are still moving, hold the post until the proof set is strong enough.

### 4) Channel Baseline

- Primary channels: LinkedIn and Facebook.
- Secondary channels and repurposing path (when approved): X, YouTube, Instagram, Google Business Profile posts, testimonials/reviews surfaces, and newsletter highlights.
- Keep visual identity and terminology consistent across channels.
- Match the channel to the message: stakeholder proof on LinkedIn, community visibility on Facebook, deeper evergreen assets on YouTube and the website.

### 5) Content Architecture Baseline

- Use the four-phase project lifecycle: deployment, active tempo, closing, and legacy.
- Use the five-angle rotation for content balance:
  - Macro progress
  - Technical execution
  - Logistics and coordination
  - Safety and team discipline
  - Spec vs reality validation
- When the job is completed and owner approval is in place, include a podcast post-interview with Jeremy as a legacy trust asset and recap format.

### 6) Cadence and Length Parameters (Adjustable)

Default baseline per active project:

- Cadence: **1-2 posts per week**.
- Weekly format mix:
  - 1 progress/evidence post
  - 0-1 technical or logistics post
  - 0-1 trust/social-proof post

Length baseline by post intent:

- Snapshot update: 60-120 words
- Standard progress update: 120-220 words
- Milestone summary/case-study teaser: 220-400 words

Project-specific adjustment guidance:

- Increase cadence when milestone frequency and approved media volume are high.
- Reduce cadence when project activity is low, stakeholder sensitivity is high, or approvals are pending.
- Shorten copy for fast updates; expand copy only when context improves client decision clarity.
- Increase cadence only when verified milestones, media quality, and owner sensitivity all support it.

### 7) Public-Sector Security Tier Adaptation (Required)

- For government and grant-funded work, adapt communication to project security sensitivity before publishing any external content.
- Apply documented review gates for confidentiality levels, including confidential and top-secret restrictions.
- Use security-level release filters so public-facing updates include only approved, non-sensitive details.
- Keep all government/public-sector messaging compliance-forward, factual, and owner-approved.
- When uncertainty exists, choose the lower-risk release path and wait for explicit approval.

## Operational Guardrails

- Keep copy client-safe: no hard dollar thresholds, no market-trader phrasing.
- Preserve accreditation and trust references on relevant posts.
- Add alt text and readable structure for accessibility.
- Keep naming aligned with canonical SEO and route terminology.
- Avoid internal jargon, inflated certainty, and militarized phrasing that reduces clarity for owner or community audiences.

## Approval Baseline

Before publishing, verify the following so the content stays aligned with MH standards and field reality:

1. Brand terminology matches MH standards.
2. Claims are evidence-backed and project-approved.
3. Cadence and post length choices are documented for that project's context.
4. Any exception from baseline is noted with reason.

## Relationship To Marketing and Sales Strategy

This document defines the minimum parameter framework for all projects. Project-level marketing plans and sales follow-up plans can tune cadence, content length, and emphasis by lifecycle phase, owner goals, and delivery realities, but they should not undercut MH proof standards or relationship-first messaging.
