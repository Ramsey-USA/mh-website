## Quick Summary

This directory is the shared parameter cluster for MH marketing and sales strategy. It centralizes the reusable baselines that should stay consistent across campaign planning, pursuit follow-up, public narrative, and post-award stakeholder communication.

Use this index when you need the shared rules for messaging cadence, approvals, lifecycle phases, or cross-functional handoffs.

## Purpose

This directory is the shared parameter cluster for MH marketing and sales strategy. It centralizes the reusable baselines that should stay consistent across campaign planning, pursuit follow-up, public narrative, and post-award stakeholder communication.

Use this directory when a rule set is meant to be reused across guides instead of living inside only one guide.

## Parameter Baselines

- **[Social Media Branding Parameters (Shared Campaign Baseline)](./social-media-branding-parameters.md)** - Primary shared source for message hierarchy, channel controls, cadence guidance, and security-tier communication rules.
- **[Lifecycle Campaign Parameters](./lifecycle-campaign-parameters.md)** - Canonical phase names, week ranges, slogan lines, and campaign-stage intent across deployment, active tempo, closing, and legacy.
- **[Proof and Approval Parameters](./proof-and-approval-parameters.md)** - Shared evidence gates, hold conditions, approval checks, and external release discipline.
- **[Pursuit and Handoff Parameters](./pursuit-and-handoff-parameters.md)** - Shared opportunity-fit rules, approval authority, mission-parameter discipline, and pursuit-to-operations continuity expectations.

## Usage Rules

- Put reusable strategy baselines here when they apply to both marketing and sales surfaces.
- Keep guide-specific interpretation inside the guide, but move the underlying parameter set here when it becomes cross-functional.
- Update the Marketing Strategy Guide and Sales/Estimating Guide in the same change whenever one of these shared baselines changes.
- Keep the MH primary line, proof discipline, and relationship-first language consistent with [Brand Constants](../../branding/brand-constants.md) and [Brand Messaging Strategy](../../branding/strategy/messaging.md).
