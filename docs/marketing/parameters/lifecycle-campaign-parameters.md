# Lifecycle Campaign Parameters (Shared Phase Baseline)

**Category:** Marketing - Strategy Baseline  
**Last Updated:** July 31, 2026  
**Status:** Active

## Purpose

Define the shared lifecycle naming, week ranges, slogan lines, and phase intent used across MH marketing and sales materials whenever project communication follows the build cycle from ground break through legacy follow-up.

Use this file when campaign timing, phase naming, stakeholder recap language, or cross-functional communication needs one canonical lifecycle baseline.

## Canonical Lifecycle Parameters

### Phase I: Deployment

- Weeks 1-8
- Working label: Ground Break and Earthwork
- Slogan line: **Break Ground, NOT the Schedule.**
- Primary communication intent: show early progress without overstating completion.
- Typical proof set: site prep, trenching, grading, foundation preparation, approved drone overview, early logistics coordination.

### Phase II: Active Tempo

- Weeks 9-24
- Working label: Vertical Build and MEP Rough-In
- Slogan line: **Raise the Pace, NOT the Pressure.**
- Primary communication intent: show disciplined production, coordination, and visible progress during the busiest field window.
- Typical proof set: structural framing, material deliveries, trade coordination, rough-in progress, safety posture, milestone-driven field updates.

### Phase III: Closing

- Weeks 25-32
- Working label: Finishes and Ribbon Cutting
- Slogan line: **Cut the Ribbon, NOT the Cord.**
- Primary communication intent: show clean closeout, stakeholder confidence, and ongoing relationship continuity after physical completion.
- Typical proof set: finishes, walkthroughs, cleaned staging areas, ribbon-cutting moments, handoff visuals, approved stakeholder recap content.

### Phase IV: Legacy

- Weeks 33-36
- Working label: Project Debrief and Podcast
- Slogan line: **Finish the Project, NOT the Partnership.**
- Primary communication intent: turn completed work into durable trust assets for referrals, case studies, and thought leadership.
- Typical proof set: executive interviews, cost-variance review takeaways, owner-approved case studies, podcast sessions, long-tail recap assets.

## Usage Rules

- Use these phase names and week ranges consistently in marketing plans, project recaps, and stakeholder-facing campaign references.
- When a project timeline compresses or extends, keep the phase names but adjust week references only when the new range is documented and approved.
- Keep slogan lines secondary to the MH primary line: **Built on Quality, Backed by Trust.**
- If sales follow-up content will be reused by marketing, align the recap language to the current lifecycle phase before release.
