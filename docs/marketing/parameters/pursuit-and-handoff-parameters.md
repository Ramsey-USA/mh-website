# Pursuit and Handoff Parameters (Shared Continuity Baseline)

**Category:** Marketing - Strategy Baseline  
**Last Updated:** July 31, 2026  
**Status:** Active

## Purpose

Define the shared continuity parameters used when MH moves from pursuit into proposal, from proposal into award, and from award into operations while keeping stakeholder communication aligned across sales and marketing.

Use this file when opportunity-fit rules, approval authorities, mission-parameter discipline, or handoff expectations need one canonical reference.

## Canonical Pursuit Parameters

### Opportunity Qualification

- Confirm the client relationship is real and reachable.
- Confirm the project fits MH capacity, geography, schedule, and service mix.
- Confirm decision authority is visible enough to support a credible pursuit.
- Stop early when fit, timing, or access is too weak to support disciplined estimating.

### Mission Parameters Standard

- Replace generic scope language with explicit Mission Parameters.
- Define inclusions, exclusions, assumptions, clarifications, allowances, and alternates clearly.
- Tie every major assumption back to a visible project condition or known requirement.
- Write the scope so leadership, operations, and the owner can all understand where responsibility begins and ends.

## Canonical Approval Authority Parameters

| Value              | Required Approval Authority                     |
| ------------------ | ----------------------------------------------- |
| Under $25,000      | Project Manager (Alpha, Bravo, or Charlie Wing) |
| $25,000 to $50,000 | Chief Operating Officer (XO)                    |
| Over $50,000       | President and CEO (CO)                          |

Use this matrix before presenting estimates, proposals, or post-contract change orders to a Client Partner.

## Canonical Handoff Parameters

- Treat handoff as a continuity event, not an administrative file transfer.
- Transfer Mission Parameters, Ground Truth intelligence, and approved assumptions into operations in a format leadership can defend later.
- Coordinate with marketing when post-award communication, recap assets, or public narrative may continue after award.
- Keep owner trust, scope clarity, and approval history intact from pursuit through project execution.
