# MHC Tool Box Talks Library

Purpose: canonical source folder for Toolbox Talk content used to extract daily
field-briefing topics into operations-manual day-to-day execution standards.

## Usage contract

- Place daily Toolbox Talk source files here (PDF, DOCX, or approved source text).
- Maintain full-year rotation coverage to avoid stale repeated topics.
- Include date/topic metadata when available for scheduling traceability.
- Do not place generated summaries or final PDFs here.

## Extraction scope for operations manual

- Daily hazard focus themes
- Task-specific caution points
- Crew briefing prompts and checkpoints
- Required follow-up actions/documentation
- Rotation cadence controls to prevent staleness

This folder is an upstream source for day-to-day operations sections in
MHC-Operations-Manual.
