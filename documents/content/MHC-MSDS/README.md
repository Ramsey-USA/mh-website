# MHC MSDS Library

Purpose: canonical source folder for Material Safety Data Sheet (MSDS/SDS)
content used to extract hazard, handling, storage, PPE, and emergency-response
requirements into operations-manual procedures.

## Usage contract

- Place supplier/source MSDS/SDS files here (PDF, DOCX, or approved source text).
- Keep files organized by material family and revision/effective date.
- Preserve original source naming where possible for traceability.
- Do not place generated summaries or final PDFs here.

## Extraction scope for operations manual

- Hazard identification and signal words
- Required PPE and exposure controls
- Storage/segregation constraints
- Spill/first-aid/emergency actions
- Disposal and environmental controls

This folder is an upstream source for day-to-day operations sections in
MHC-Operations-Manual.
