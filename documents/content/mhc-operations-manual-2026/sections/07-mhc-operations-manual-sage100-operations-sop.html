1. Mission Purpose

Define disciplined SAGE100 operations for accurate financial controls, job-cost integrity, and auditable alignment between project execution and accounting records.

2. Command Ownership and Authority

Systems-of-record modules in scope:

  • General Ledger (GL)
  • Accounts Payable (AP)
  • Accounts Receivable (AR)
  • Job Cost
  • Payroll
  • Purchasing
  • Inventory

Authority model:

  • XO is accountable for policy and final operational control.
  • CFO function is advisory only and currently executed by XO until role is filled.
  • PMs and PEs provide project control inputs.
  • CPCO provides preconstruction and estimate-assumption alignment input.

3. Required Inputs

  • Approved contract and budget baselines
  • Approved change-order records
  • Vendor and subcontractor invoices
  • Payroll/timekeeping feed (HH2 workflow outputs)
  • Purchasing and inventory movement data
  • PM monthly forecast and variance narrative

4. Required Outputs

  • Posted and reconciled transactions per module
  • Updated job-cost position by project
  • AP/AR status aging reports
  • Payroll posting reconciliation
  • Monthly control package for XO review

5. SOP Steps

Step 1 - Intake and Validation

  • Validate source documents before posting.
  • Confirm approval authority is documented for each financial event.
  • Reject incomplete or unauthorized entries for correction.

Step 2 - Module Posting Execution

  • Post transactions to relevant modules (GL/AP/AR/Job Cost/Payroll/Purchasing/Inventory).
  • Verify cost-code alignment and project references.
  • Confirm cross-module consistency where linked transactions exist.

Step 3 - Reconciliation and Exception Control

  • Reconcile module balances to project control records.
  • Investigate and resolve posting variances.
  • Record exception causes and corrective action.

Step 4 - Project Financial Control Sync

  • PM and PE review project-level financial posture.
  • CPCO reviews estimate-to-actual patterns where preconstruction assumptions drive variance.
  • XO validates corrective actions for exceptions.

Step 5 - Reporting and Command Review

  • Produce monthly control packet for XO.
  • Present financial control exceptions in Monday operations meetings when project impact is active.
  • Escalate severe or systemic controls issues through command path.

6. Controls and Thresholds

  • No posting without approved source authority.
  • No module-close completion without reconciliation.
  • Job-cost updates must align to approved contract and change records.
  • Payroll entries must trace to approved HH2 control outputs.
  • Financial exceptions with material project impact require XO review before close.

7. KPI and Review Cadence

Weekly (operational watchlist):

  • Open posting exceptions
  • Unreconciled project entries
  • Aging AP/AR risks affecting mission execution

Monthly (control close):

  • Reconciliation completion rate
  • Posting accuracy rate
  • Estimate-to-actual variance trend by project

Quarterly audit:

  • Controls compliance score
  • Repeat exception rate
  • Audit trail completeness score

8. Evidence and Record Location

Primary evidence:

  • SAGE100 transaction records and module reports

Supporting evidence:

  • Reconciliation packets
  • Exception logs
  • PM/PE financial review notes
  • Monday meeting minutes when escalations occur

9. Escalation Path

Standard path:

  • PM/PE -> XO -> CO

Specialized path:

  • CPCO -> XO -> CO for preconstruction and estimate-risk exceptions.
  • CHENG -> XO -> CO for compliance-linked financial controls risks.

10. Non-Compliance Response

  • First breach: correction cycle with documented owner and deadline.
  • Repeat breach: XO-led controls review and retraining.
  • Severe breach: command intervention, temporary posting hold, and CO notification.
