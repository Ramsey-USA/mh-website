# MHC Operations Manual - Review Packet Checklist

Status: Draft v0.1
Purpose: Standardize chapter-level review packet assembly before approval routing.

## 1. Packet Contents (Required)

- Chapter draft document
- Change summary (what changed and why)
- Impacted appendices list
- Open risks and decision requests
- KPI/control impact statement
- Evidence sample references (if applicable)

## 2. Review Order

Mandatory approval sequence:

1. CHENG review
2. HR review
3. XO approval
4. CO final approval

## 3. Quality Gate Checks

- Command ownership and backup owner are defined.
- SOP steps include clear responsibilities.
- Controls and thresholds are explicit and auditable.
- Escalation path aligns with command doctrine.
- Evidence location is specified.
- Terminology aligns with current command model (CO/XO/Master Chief/CHENG/CPCO).

## 5. Outcome Logging

- Approved
- Approved with changes
- Returned for rework
- Deferred

Each outcome requires:

- Reviewer name
- Date
- Comment summary
- Required action owner and due date
